# Donations

Oneprobe is free to self-host. If it replaces a Datadog dashboard week,
donate.

There is no paid tier, no subscription, and no feature gated behind
money. Everything Oneprobe does — scraping, the query subset, alerting,
the Datadog dry-run migrate — works identically whether you donate or
not.

## Optional memo

If you want a GitHub handle credited, include it in the transfer memo
where your wallet supports one (e.g. `@yourhandle`). This is purely for
the maintainer's thank-you list — it changes nothing about the
software.

## In-product surfaces

The same addresses appear in:

- `oneprobe donate` (CLI)
- the `/donate` HTTP endpoint on a running server
- README.md

Wallet changes require 4/4 maintainer consensus and 30 days of public
notice — see GOVERNANCE.md.
